At Ria Money Transfer, I led the development and deployment of an end-to-end forecasting pipeline to predict transaction volumes for each country and agent up to 7 days ahead. This project aimed to automate and improve the accuracy of a previously manual process, with key performance targets to reduce surplus capital and lockout rates by ensuring liquidity while minimizing idle funds.

After presenting the proof of concept to the CFO and securing project approval, I structured the initial notebook code into a scalable, object-oriented Python package enabling parameterized execution across different currencies and data types. The pipeline incorporated machine learning models—primarily Extreme Random Forests—trained daily with data stored and processed in AWS (S3, Athena, Glue, ECR). I designed a relational SQL database to track model outputs, performance metrics (e.g., adjusted MAPE in the range of 10-15%), data quality, and experimental results, allowing comprehensive monitoring and iteration.

The deployment included CI/CD pipelines using AWS Glue jobs, GitHub Actions, and Terraform, in collaboration with the DevOps team. The forecasting results demonstrated a daily reduction of $500,000 in underfunding for Mexico and a 35% decrease in lockout rates compared to the manual approach. Additionally, the automated pipeline reduced prediction generation time from several hours to approximately 4 minutes per corridor.

To facilitate stakeholder engagement, I created a Quicksight dashboard updating daily with forecasting results. I also supported cross-functional teams by sharing knowledge on forecasting methodology, data quality troubleshooting, and deployment strategies, contributing to improved scalability and operational robustness.
